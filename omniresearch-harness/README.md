# omniresearch-harness

Autonomous research orchestrator — runs multi-agent coding swarms (omnigent) through fixed-budget, eval-gated ML research loops (autoresearch-mlx).

> **Agentics × AI** — Orchestrator → planner → workers → critic drive a data-curator → trainer → evaluator → deployer ML loop, with a swarm-bus MCP and shared memory.
>
> Minted with [`metaharness`](https://github.com/ruvnet/agent-harness-generator) from two source repos. WASM kernel, multi-host support, witness-signed releases.

## Install

```bash
npm install -g omniresearch-harness
omniresearch-harness init
omniresearch-harness doctor
```

## Agents

| Agent | Role | Lineage |
|---|---|---|
| `orchestrator` | Routes work and owns the goal state. | omnigent |
| `planner` | Builds the dependency-aware plan. | omnigent |
| `worker` | Executes one task and reports. | omnigent |
| `critic` | Reviews outputs before they land. | omnigent |
| `data-curator` | Builds and documents the dataset. | autoresearch-mlx |
| `trainer` | Runs reproducible, fixed-budget training jobs. | autoresearch-mlx |
| `evaluator` | The honest eval gate (`val_bpb`). | autoresearch-mlx |
| `deployer` | Commits the winner / reverts the regression. | autoresearch-mlx |

## The research loop

`/research-loop` runs one bounded iteration:

```
planner ── reads program.md + results.tsv
   │
trainer ── edits train.py, runs fixed-time MLX experiment
   │
evaluator ─ computes val_bpb vs. baseline
   │
critic ──── accept (strictly lower val_bpb) / reject
   │
deployer ── git commit + append results.tsv  │  git revert
```

This harness ships with the **claude-code** adapter.
